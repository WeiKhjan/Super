# 超时空英雄传说 · 移动重制版

致敬 1996 年宇峻科技（UserJoy）DOS 经典战棋游戏《超时空英雄传说》的**手机网页重制版**。
纯 HTML5 Canvas + JavaScript，无需安装、无外部依赖，手机浏览器打开即可游玩，也可「添加到主屏幕」离线全屏运行。

> 本作为粉丝向非官方重制，所有像素美术、音效、地图与剧情文本均为重新创作，仅保留原作的世界观与玩法精神。

## 游戏内容

- **故事**：来自地球的年轻作家孟祁误闯时空裂缝，来到科隆多世界，与杨铁一同寻找大剑师张青，对抗迦纳大帝与黑魔神。
- **8 场战役**：序章 · 进入异世界 → 逃出紫霞山 → 寻找大剑师 → 林谷的大剑师 → 古战场的亡灵 → 斯里兰的黑暗军 → 帝都决战 → 终章 · 黑魔神降世
- **7 名可用角色**：孟祁、杨铁、雪莉、菲娜、张青、罗德、刘队长
- **转职系统**：Lv5 / Lv10 / Lv15 自动转职，例如 剑士 → 高级剑士 → 银剑士 → 黄金剑士；骑枪兵最终可成为能飞行的飞马骑士
- **法术与召唤**：火球术、雷击术、极热光束、治疗术、圣光术（对亡灵双倍）、召唤精灵；敌方土神巫会召唤豬頭龍
- **地形**：森林、山地、村庄、城堡提供防御与回避加成；村庄每回合回复 HP；骑兵难以通过森林山地，飞行单位无视地形
- **反击、暴击、宝箱、商店、装备、自动存档**

## 操作（触屏）

1. 点击我方角色 → 蓝色格子为可移动范围，红色为攻击范围
2. 点击目的地移动 → 底部选择「攻击 / 法术 / 道具 / 待机 / 取消」
3. 选择目标后会显示伤害预测，再点一次或按「确认」执行
4. 点击敌人可查看其移动与攻击范围
5. 全员行动完毕后自动进入敌方回合

## 本地运行

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

（直接双击 `index.html` 也能玩，但离线缓存功能需要通过 http(s) 访问。）

## 发布到手机上玩（GitHub Pages）

仓库 Settings → Pages → Source 选择 `Deploy from a branch`，分支选 `main`、目录 `/ (root)`，保存后即可通过
`https://<用户名>.github.io/<仓库名>/` 在手机上打开。

## 文件结构

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构 |
| `css/style.css` | 移动端优先的界面样式 |
| `js/data.js` | 地形、职业、法术、道具、角色、章节地图与剧情 |
| `js/sprites.js` | 16×16 像素角色与地形贴图（代码生成，无图片素材） |
| `js/game.js` | 战斗引擎、AI、渲染、音效、营地与存档 |
| `sw.js`, `manifest.webmanifest` | PWA 离线缓存与「添加到主屏幕」 |

## 修改与扩展

- 新增章节：在 `js/data.js` 的 `CHAPTERS` 中加入一项（地图为 10×13 字符画）
- 平衡测试：在浏览器控制台执行 `__autoplay()`，AI 会自动打完所有章节并返回结果
