# 超时空英雄传说 · 移动重制版

致敬 1996 年宇峻科技（UserJoy）DOS 经典战棋游戏《超时空英雄传说》的**手机网页重制版**。
纯 HTML5 Canvas + JavaScript，无需安装、无外部依赖，手机浏览器打开即可游玩，也可「添加到主屏幕」离线全屏运行。

> 本作为粉丝向非官方重制。关卡结构、人物、职业、法术与道具体系依照原作资料整理；
> 对白为依原作剧情**重新撰写**的精简版本，像素美术、音效与地图均为重新创作，未使用原作的图像与音乐素材。

## 系列合集

开启游戏后先在主画面选择作品：

| 作品 | 状态 |
| --- | --- |
| 超时空英雄传说（1996） | 全 35 关 |
| 超时空英雄传说 2：复仇魔神 | 全 55 关（含 8 个隐藏关），一周目约 40 关；南北两条路线、四位女主角、多重结局与两种最终 BOSS |
| 超时空英雄传说 2 外传：北方密使 | 全 67 关（含 7 个隐藏关）；男主角白志超、女主角娜塔莉亚两条主线，第四部合流；三种结局 |
| 超时空英雄传说 3：狂神降世 | 全 64 关（含 3 个隐藏关）；A/B 两线再分 A1/A2/B1/B2 四路线、七种结局 |

复仇魔神加入了二代的系统：移动点数制（行动后可再移动）、方向与背后攻击、高低差、Lv11 起的自由循环转职、好感度与情侣合技、剧情选项、隐藏关与依旗标分歧的路线和结局（`js/g2/`）。

北方密使沿用二代引擎，再加上：开局选择主角（男女双主线）、侧面 ×1.25 / 背后 ×1.5 的原作倍率、主角专属的 6 种转职、靠道具解锁的隐藏职业（鱼人、吸血鬼、女妖、小丑）、职业特殊能力（连击、吸取、灵击、搜索、开锁）、隐藏宝物与上锁宝箱、秘籍学招、刑天与秋月的合击「有无相生」（`js/g3/`）。

狂神降世换到新大陆法尔马立克。原作的半即时 CT 制不采用，沿用系列的回合制引擎，并加入：开场五道「前导问答」决定克荷林的能力、Lv5 起的自由转职与「职业经历」、各英雄专属且二选一的隐藏职业（例：剑圣需斗剑士系 Lv16 + 修士系 Lv5）、双方都转为隐藏职业才能发动的合技（太古机兵、暴风散弹箭、混沌脉冲、超热燎原火）、会变身的最终 BOSS 狂神，以及路线 × 好感度决定的结局（`js/g4/`）。

## 内容（一代）

- **全 35 关主线**：从「序章 · 进入异世界」到「终章 · 黑魔神」，依原作顺序与胜负条件（含回合限制、护送 NPC、取得宝物等）。
- **19 名角色**：孟祈、杨铁、克莱恩、史莱德、欧兹、雪儿、茱笛、无双、曲圆吉、郝西瑟、莲乔伊、戴薇拉、坎培特、刘队长、拉拉、韩凯蒂、哈克、奥古斯都、张青——按原作剧情加入与离队。
- **转职分支**：多数职业在中期转职时可选原作路线或新路线——魔法剑士、圣骑士、狂战士、忍者、游侠、武僧、时空术士、召唤士、风鹰术士、月影狼、冰龙，各有成长、移动、专属招式与造型；营地可查看「职业树」。
- **原作职业系**：孟祈专属的作家系（作家 → 侠客 → 剑道家 → 圣剑士 → 剑侠 → 剑王 → 剑圣），以及剑士、骑兵、战士、武士、弓箭、牧师、咒术师、法师、龙族、鹰族、狼族等，达到等级自动转职（地图形象与立绘随职阶换装），并播放全屏**转职演出**（光柱、新旧形象交替闪烁、新职业登场与专属号角）。
- **魔法与战技**：地 / 火 / 风 / 水 / 黑暗 / 神圣 / 召唤七系法术；各职业有专属战技——剑术系的单人剑式与需要相邻剑术伙伴的**双人剑式**、骑兵**枪术**、战士**斧技**、武士**刀术**、弓手**箭术**、鹰族与狼族的天赋战技；直线招式不分敌我。
- **异常状态**：石化、冻结、失明、中毒、禁锢、无法反击；增益与减益。
- **兵种相克**：依原作说明书的修正表。
- **三种结局**：担任迦纳君主 / 留在科隆多 / 回到地球，附各角色后日谈。
- **仿原作风格的美术**：手绘风半身立绘（全 19 名英雄与所有敌人）、32×32 立体着色单位、2.5D 地形（山岩、树林、城墙、石柱、村屋），以及原作式的侧视**战斗画面**（关节动画的战斗人物：挥砍、突刺、骑乘冲锋、拉弓、受击、闪避、倒下，服装随职阶由布衣到金甲）。
- **原创配乐与音效**：标题、剧情、我方回合、敌方回合、首领战、终章、营地、结局共 8 首曲子 + 胜利 / 失败 / 升级短曲 + 25 种音效，全部以 Web Audio 即时合成（无音频档案）。
- 营地：装备（武器 / 防具 / 饰品）、一键自动装备、商店（随进度解锁）、出击人员选择；难度「简单 / 标准」；自动存档。

## 操作（触屏）

1. 点击我方角色 → 蓝色格子为可移动范围，红色为攻击范围
2. 点击目的地移动 → 选择「攻击 / 法术 / 道具 / 待机 / 取消」
3. 选择目标后显示伤害预测（含相克倍率），再点一次或按「确认」执行
4. 点击敌人可查看其移动与攻击范围；全员行动完毕后自动进入敌方回合

## 本地运行

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 发布到手机上玩（GitHub Pages）

仓库 Settings → Pages → Source 选择 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存后即可通过
`https://<用户名>.github.io/<仓库名>/` 在手机上打开。

## 文件结构

| 文件 | 内容 |
| --- | --- |
| `index.html` / `css/style.css` | 页面与移动端优先的界面 |
| `js/data.js` | 地形、相克表、法术、道具、职业、英雄 |
| `js/stages/*.js` | 35 个关卡（地图、单位、事件、对白） |
| `js/story.js` | 三种结局与后日谈 |
| `js/sprites.js` / `js/sprites3.js` | 单位精灵底稿与 32×32 着色升级、2.5D 地形 |
| `js/portraits.js` | 手绘风半身立绘（代码生成） |
| `js/audio.js` | 原创配乐与音效（Web Audio 合成） |
| `js/duelfig.js` / `js/duel.js` | 侧视战斗画面的动画人物与演出 |
| `js/spellfx.js` | 地图上的法术演出 |
| `js/promote.js` | 转职演出 |
| `js/battle.js` | 战斗规则、AI、渲染、操作 |
| `js/game.js` | 存档、营地、出击、剧情流程、结局 |
| `sw.js`, `manifest.webmanifest` | PWA 离线缓存与「添加到主屏幕」 |
| `tools/build_single.py` | 打包成单一 HTML（托管用） |
